# Series identity: «هتحلها ازاي؟»

Values live in `config/series.json` (identity) and `config/theme.tokens.json` (visuals); edit them there.
The internal skill name stays `egyptian-ux-reels`.

| | |
|---|---|
| Display name | **«هتحلها ازاي؟»**, exactly this spelling |
| Visual concept | **UX Debugger**: a designer's inspection tool around a real or illustrative product |
| Audience | UI/UX practitioners |
| Tone | Professional, practical, thoughtful, visually engaging |
| Narration | Eyad's own recorded voice (Egyptian Arabic, English UX terms as spoken) |

## How the identity appears
- A small identifier inside the debugger toolbar (inspect glyph + «هتحلها ازاي؟»). Nothing else carries the brand.
- No spoken introduction, no opening bumper, no outro card. Every episode starts directly on the spoken hook and the
  visual example.
- **Transition phrase.** If the recording contains «طيب هتحلها ازاي؟», that moment becomes the visual turn from inspecting the
  situation to exploring the solution (e.g. the inspector closes, the mode chip changes, the change step begins).
  Never insert, repeat, duplicate on screen or rewrite it. If it isn't in the recording, there is no such moment.
- **Closing.** Use the closing discussion question from the approved script, as recorded. Captions show it. Don't add a CTA.

## What the series is not
- Not a wrong/right comparison show: present context, the trade-off of the change, and when it applies.
- Not a dashboard: no fake scores, ratings, metrics, console logs, code walls or decorative panels.
- Not a phone-mockup show: no full device frame held on screen through the episode.

## Turn line variants
Some scripts use their own turn line instead of «طيب هتحلها ازاي؟» (e.g. «طب هما حلوها ازاي؟» when the episode shows how a
product already solved it). Use that line, as recorded, as the inspect → solve turn; the toolbar identifier stays «هتحلها ازاي؟».
