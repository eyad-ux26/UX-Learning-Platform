S3-16 · Certificate and Share on LinkedIn (7 Nov)

Eyad: a better certificate, a better phone view, and Share on LinkedIn that opens a ready post with the certificate image. The art is drawn at 1200 × 628, LinkedIn's link-preview size, so the page, the PNG download and the og:image are the same picture. Phones get a tall version of the same art. LinkedIn can't take an image through a link, so the post links to the public certificate page, and LinkedIn shows the certificate as the link's image. The post text is copied too, in case LinkedIn drops it. Add to LinkedIn profile fills in the Licenses & certifications form. Approved by Eyad (7 Nov): the first time a certificate is issued, a one-time sheet asks the learner to check the name it will print. If the name looks like part of an email, it opens ready to edit. A Name on certificates row on the page links to Settings afterwards. Built (PR #213): Download PDF makes a real PDF file, and phones keep the landscape certificate scaled to fit instead of the stacked tall version shown below. Built (PR #218): the share sheet offers 3 post versions as chips above the post, and the post text can be edited before sharing; the edited text is what gets copied and sent to LinkedIn. The phone share sheet was fixed too. Then PR #219: the versions start in English, with a Translate to Arabic / Show in English toggle that switches all three, and the selected version uses the selected chip style with a check icon. On phones, LinkedIn's app ignores prefilled text sent in a link, so the post text is copied, LinkedIn's share composer opens with the certificate link preview, and a toast tells the learner to paste the text. Desktop is unchanged. Frame 4 still shows one fixed post.
