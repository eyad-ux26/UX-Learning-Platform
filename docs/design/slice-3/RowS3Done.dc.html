S3-17 · Completed paths on the Paths tab (7 Nov)

Eyad: when a path is done, the Paths tab doesn't show it. A path is completed when its certificate exists, meaning every skill is Shown. Lesson % alone isn't enough, so a path finished by SQL or by retests still counts. Completed paths move to their own Completed section under Your paths. Each gets a mint card, a check badge on the picture, a Completed chip and the line N skills Shown · Certificate ready, with no % bar. Tapping it opens the path page in its finished state (S3-13: Review this path, See your certificate). A path whose lessons are all done but still has skills to show stays in Your paths with an amber N skills to show chip, so the learner knows the skill check is what's left.
