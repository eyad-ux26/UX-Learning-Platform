# UXGate brand facts

The look must come from UXGate's existing brand material: see the images in `brand-resources/` (`uxgate-brand-overview.jpg` shows all of them together).

## Logo

- The original UXGate logo, **unchanged**: an open door with a small face, gradient #60BEBB → #005F99, with the spaced-out "UXGATE" wordmark.
- Files in `logos/`: full colour (light grounds), white and inverse (dark grounds, videos), black (one colour), icon and icon mark (app icon, favicon, small spaces), vertical, wordmark.
- Never recolour, stretch, add effects or retype the wordmark.
- Logo animations already exist for review (splash, gate opens, loading, checking, success, idle blink); see `brand/uxgate-logo-animations/` in the project files.

## Look and feel in the brand material

- Clean, airy layouts on ice or night grounds; big bold Arabic headlines in navy (white on night) with a blue or cyan subtitle line.
- Fully rounded **pill buttons** and labels; cyan pills with navy text for lists and highlights.
- Soft rounded cards (pale cyan, mint, white with thin outline) holding a screenshot or illustration.
- A small rotated **star badge** ("جديد", new) on cards.
- Glossy 3D objects (trophy, bell, gift, newspaper) as occasional illustrations.
- Light decorative lines (wavy strokes, dot grids) at the edges, never behind text.
- Footer pattern: logo on one side, www.uxgate.org on the other.

## Type

- **Arabic: Cairo** (Google Fonts). Decided by Eyad.
- **English: Titillium Web** (Google Fonts). Cairo's own Latin letters are based on Titillium, so both scripts share the same shapes, weights and height. Replaces the earlier fonts, which felt too generic.
- No other UI fonts. Use tabular numbers for counters and XP.

## Icons

**Phosphor Icons** (free, MIT, 1,500+ icons, regular, fill and duotone weights); its rounded shapes match the rounded door of the logo. Use regular for interface icons and fill for active or status icons. If an icon is missing, use **Tabler Icons** outline at 1.5 stroke so it looks the same. No emoji as icons.

## The same system drives videos

Lesson videos (Remotion, 1080 × 1080 at 30 fps, and 1080 × 1920 for reels) use the night look, the white logo, cyan for key words, and the same fonts and icons. Keep this in mind when defining colours, type sizes and motion.
