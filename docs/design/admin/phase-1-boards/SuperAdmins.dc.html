The rules

  • Founding super admin. uxgate8@gmail.com, the business account. Only the owner can change it, with a database step.
  • Giving super admin. The person must already be an active admin with two-step sign-in on. You confirm with your passkey or password and type GRANT SUPER ADMIN.
  • 24-hour cooling period. On by default. If it is turned off for one grant, a second super admin must approve it.
  • Everyone is told. Every super admin gets an email for each grant and removal. All of it is in the audit log.
  • Removing. Any super admin can remove another, except the founding one. There is always at least one active super admin.
  • Lost founding account. Recovery is a written database step by the owner, not a button in the panel.
