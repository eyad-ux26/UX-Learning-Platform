Everything the team needs on launch day at uxgate.org/admin: who can get in, who the learners are, how they get help, and where the money is. Phase 2 adds the tools to grow: content, media, quality, reports, communications, settings and system health. Each board names the requirement ids it covers from “UXGate Admin Panel: Requirements”.

The idea

UXGate is a design-tool world, so the admin reads like one, in a calm work density: the menu is a layers panel, the open item wears the selection frame, and every detail page has an inspector on the right with the facts and the actions. No rewards, colours or motion from the learner app.
